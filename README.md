Python Learning Journey:
Learning Python core and advanced concepts through hands-on examples and game development.

About:
This repository documents my hands-on Python learning journey.

For every Python concept, I:
- Study the concept
- Write standalone runnable examples
- Execute the programs and verify the output
- Commit the working solution
- Apply the concept to an evolving capstone game

The objective is to build practical Python skills through consistent, incremental development rather than isolated code snippets.


Goals:
- Learn Python from fundamentals to advanced concepts.
- Build strong programming fundamentals.
- Write clean, readable, and maintainable Python code.
- Develop problem-solving skills through practical examples.
- Build an end-to-end Python game as a capstone project.
- Showcase Python skills through a public GitHub repository.

How to Run Examples:
Verify Python
python3 --version

Verify `venv` is available
python3 -m venv --help

If it is not installed:
sudo apt update
sudo apt install python3-venv

Create a virtual environment
python3 -m venv .venv

Activate the virtual environment
source .venv/bin/activate

Run an example
python 01_variables/example1.py

Deactivate when finished
deactivate
